# MR-03 closeout checklist

MR-03 is active after MR-02's completed closeout. Its six frozen acceptance
clauses remain unchanged. Component evidence does not yet certify final process
validation.

| Gate | Implementation and verification | Remaining work |
|---|---|---|
| A1: complete serialized accounting | Go typed projection and outer repacking count complete UTF-8 JSON, metadata, trust wrappers and empty envelopes | Audit current tests and run final owner suite |
| A2: final hard limits | Complete provider-body byte admission, caller/operator intersection, exact-body commitment; unsupported token limits and reserves refuse before dispatch | Verify inherited asynchronous/task paths and final process boundaries |
| A3: protected constraints and partial sufficiency | Complete hard-rule recall before optional evidence; retained-source coverage after outer packing | Audit authority and required-item packing; regression/process coverage |
| A4: reviewed procedures once with correct trust | Dedicated reviewed-procedure envelope; untrusted memory envelope; exact selection identity | Final projection/provider regressions |
| A5: protected transformations and bounded fallback | Retain structured user/system/developer messages verbatim; reject changed protected projections; final provider cap applies after transformation and to fallback | Complete reduction admission audit and live transform/fallback tests |
| A6: deterministic projection | Stable ordering, complete JSON serialization and projection/selection digest | Repeat assembly/packing tests against identical inputs and versions |

Token counts from legacy bytes/4 fields are explicitly unavailable provenance.
An unsupported tokenizer cannot admit a hard token limit. This checklist does not
claim support for token-capped serving, priced transformation proofs or an exact
provider tokenizer merely because byte admission passes.
