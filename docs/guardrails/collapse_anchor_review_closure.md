# Guardrail-collapse anchor review closure

This document records the provenance and review responses that support `docs/guardrails/collapse_anchors.md`. It preserves the index-vs-source verification methodology, the F001 reconciliation table, and the F002/F003 closure narrative without cluttering the anchor document itself.

## Citation verification (index vs source)

Every `file:line` citation in this document and in `collapse_recon.md` / `sampling_capability_matrix.md` / `collapse_anchors.md` is verified against the **current source tree** (the worktree at invocation time) using `grep -n` and surrounding-context inspection. The repository contract is that "Aimee index/search are authoritative for discovery; current source is authoritative for file contents when they differ" — when the index and the source disagreed on a `file:line`, the source was treated as authoritative (the index carries a `freshness=worktree_current_unverified` flag on stale entries). Each named symbol was located by its definition signature (`TYPE NAME(`) or by its exact call site (when the citation is a call site), and the surrounding lines were inspected to confirm the cited line is the intended anchor (definition, call site, or referenced line). Reviewers re-verifying a citation should reread the cited file at the cited line; if the file has moved, the citation must be updated as part of the change that moved the file.

## F002 closure (architect review)

The architect reviewer's F002 finding flagged the enforcement gate as too narrow: `PHASE_ONE_PREFIXES` in `scripts/check-collapse-anchor-gate.py` listed only five path prefixes (`src/server/`, `src/modules/guardrails/`, `src/headers/aimee_ir.h`, `src/modules/config/`, `src/modules/audit/`), leaving every other Phase 1+ surface named above -- `src/posix/`, `src/db1/`, `src/db2/`, `src/modules/roundtable/`, `src/modules/workflows/`, and the per-backend sampling files -- outside the gate's scope. The gate's prefix set has been expanded to cover every Phase 1+ surface named in this document (see `scripts/check-collapse-anchor-gate.py::PHASE_ONE_PREFIXES` and `tests/test_check_collapse_anchor_gate.py::test_gate_rejects_each_phase_one_surface_in_f002_recommendation`, which exercises one representative path from each named surface family). The carve-out for `docs/guardrails/collapse_anchors.md` itself (the `_PHASE_ONE_EXEMPT` set in the gate) preserves the bootstrap path: a PR whose sole purpose is to introduce this document is not forbidden by the gate.
