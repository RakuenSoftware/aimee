## New blockers

1. **Standalone code indexing is unavailable.** A healthy KB-free Server with the
   real embedder could not expose the fixture's symbols, callers, structure, source
   spans or blast radius. Automatic discovery was given 180 seconds; a later
   changed-commit check was given another 150 seconds. Actual workspace registration
   succeeded, but reported `ready:false`, `indexed:false`, and queued ingestion
   because the knowledge service was offline. Source lookup and project inventory
   return HTTP 503 with `dependency:local_code`. The independent readiness fixture
   also reproduced unavailable project inventory before any outage.
   This contradicts the standalone-index behavior described in the Quickstart.
   The precise runtime cause is not established. The local-code path crosses the
   memory data boundary; the source-observer guard found during inspection was
   **not demonstrated to be active**. No guard or authority requirement was relaxed.
2. **Readiness overstates SQL-backed availability.** An independent fresh stack
   created a canonical session successfully. With only its PostgreSQL stopped,
   the same operation returned HTTP 502, while `/v1/ready` returned HTTP 200,
   `ready:true` and `dependencies.db1:ok`, both immediately and 20 seconds later.
   Session creation succeeded again after SQL restoration. The earlier exploratory
   outage also failed to observe readiness becoming unavailable within its
   70-second observation window.

personal memory store. It now uses the actual `aimee` account, UID 1000. It also
compares corrected export versions to `mutation_receipt.version`, rather than the
obsolete top-level response field. The full corrected gate passed without changing
application behavior.

Exploratory beforeimages remain in the evidence. An empty CLI memory array is a

passed for these cases. An outer successful hybrid response was excluded as proof

actual failures; raw launcher exit status is not qualification.

This round validates workflow definitions and persistence, not successful graded
workflow execution. Browser pairing, real model synthesis, LUKS recovery and
retained histories have separate earlier evidence. VS Code was excluded from this
image build. No production installation or unrelated host workload was exercised.
Memory retirement checks use the retained-state contract; no Vault deletion API
was invoked.
