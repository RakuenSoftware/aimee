The [previous qualification report](egress-vault-repair-2026-10-05.md) describes
the fixture and its limits. Those limits still apply: this is Aimee's Cognee
integration, not an audit of every upstream Cognee feature. Its deterministic
CPU provider does not measure native model quality. The privileged erasure phase
does not model a registered multi-owner fleet, and dataset absence does not prove
purge of external logs, backups or snapshots. The historical upgrade and rollback
results in that report were not rerun against this image.

Main promotion exposed a stale application source snapshot. [PR #3012](https://github.com/RakuenSoftware/aimee/pull/3012)
merged after all 58 checks passed. It updates the memory, Vault and egress source
hashes without changing runtime code or external pins. Testing head
`14a76c0e9724a81ed56d83bda5ebd413aeb3fb68` subsequently passed the
[main-only repository gate](https://github.com/RakuenSoftware/aimee/actions/runs/37435739862).
The snapshot-only change does not trigger image publication; the qualified image
above remains the latest published application image. Main merge approval and
the remaining protected CI are separate release gates. This report does not
authorize merging PR #3003.
